Temperature Converter (Celsius to Fahrenheit & Fahrenheit to Celsius)

Step by Step:
1. User Input: First, I prompt the user to enter the unit (`C` or `F`) and store it in the `unidade` variable. Then, I do the same to get the `temperatura` value.
2. Celsius to Fahrenheit Conversion: I use an `if` statement to check if `unidade` equals "C". If true, the code applies the formula to convert Celsius to Fahrenheit and prints the result.
3. Fahrenheit to Celsius Conversion: Next, I use an `elif` statement to check if `unidade` equals "F". If true, it calculates the conversion to Celsius and prints the result.
4. Fallback / Error Handling: Finally, I use an `else` block to handle invalid inputs by printing `f"{unidade} incorreta"`.
